# Easy Concepts — Coaching Institute Website (demo)

Demo website for **Easy Concepts**, a women-led coaching centre in Matiala, Delhi (5.0★, 59 Google reviews).

Built with [Astro](https://astro.build) + Tailwind CSS v4. Images from Unsplash.

- `src/data/site.ts` — all business info, reviews, courses and FAQs (edit here)
- Pages: Home, Courses, About, Contact (enquiry form opens WhatsApp pre-filled)

```bash
npm install
npm run dev     # http://localhost:4321
npm run build   # static output in dist/
```

> Course details, method steps and FAQs are placeholder copy — confirm with the institute before going live.
